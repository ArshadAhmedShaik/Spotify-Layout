# 🎵 Spotify Web Player (Static UI Clone)

A **static, responsive Spotify-inspired web player interface** built with pure **HTML and CSS**.  
Perfect for frontend practice, portfolio projects, or as a clean UI prototype.

---

## 🧭 Overview

This project recreates the look and feel of the **Spotify Web Player** using semantic HTML5 and modern CSS3.  
It features a complete layout with sidebar navigation, content cards, and a persistent bottom music player — all responsive across screen sizes.

---

## ✨ Features

- 🎚️ **Sidebar Navigation** — Includes Home, Search, and Library sections with playlist and podcast UI cards.  
- 🎧 **Content Area** — Displays grouped sections like *Recently Played*, *Trending Now*, and *Featured Charts*.  
- 📌 **Sticky Top Navigation** — Action buttons and user icon remain accessible at all times.  
- 🎶 **Persistent Bottom Player** — Includes album art, song info, playback controls, progress bar, and volume slider.  
- 📱 **Responsive Design** — Adapts gracefully to smaller screens by hiding less-essential controls.  

---

## 🛠️ Tech Stack

- **HTML5** — Semantic and accessible structure  
- **CSS3** — Modern layout, flexbox, and responsive styling  
- **Google Fonts** — *Montserrat* for clean typography  
- **Font Awesome** — For consistent, scalable icons
